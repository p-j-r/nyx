# Interface contracts

The rule is ADR 19. Each contract is an exemplar file here plus a test that compares the parsed value produced by the code (`Value` equality, never text or key order, ADR 26).

| Contract | Pins | Test | Run |
|---|---|---|---|

| `kernel_stages` | public stage functions of every kernel family (R26 closed in phase 3; since phase 4 they live in the physics crates) | `crates/nyx-dfs/tests/contracts.rs`; `crates/nyx-sms/tests/contracts.rs`; `crates/nyx-ems/tests/contracts.rs`; stage composition in each crate's `tests/` | `cargo test --release -p nyx-dfs -p nyx-sms -p nyx-ems --test contracts` |
| `geom_model` | `geom` depends on `serde` and optional `rayon` only; golden feature lists (with `format`, v2.0) round-trip key for key | `crates/geom/tests/contracts.rs`; `crates/geom/tests/goldens.rs` | `cargo test --release -p geom --test contracts` |

Rewriting an exemplar: `NYX_WRITE_CONTRACT=1 cargo test ... --test contracts <test name>`. Do it only with a `VERSIONS.md` entry. None of these tests depends on frozen floating-point values, so they pass on a machine where the golden files fail (R22).

Files: `problem_spec.v3.json`, `solve_result.v2.json`, `physics_descriptors.v1.json`, `physics_{dfs,sms,ems}.v1.json`, `physics_{dfs,sms,ems}_result.v1.json`, `mesh_cells.v1.json`, `mesh_request.v1.json`, `mesh_request.schema.v1.json`, `mesh_report.v1.json`, `mesh_report.schema.v1.json`, `linalg_options.v1.json`, `material_schema.{v1,v2}.json`, `material_kitchen_sink.{v1,v2}.{toml,json}`, `material_kitchen_sink_models.v1.{toml,json}`, `store_workflow.v1.json`, `store_run.v1.json`, `script_api.v1.json`, `mcp_tools.v3.json`, `engine_commands.v1.json`, `geom_operations.v1.json`, `engine_project.v2.json`, `connect_hosts.v1.json`, `connect_report.v1.json`, `connect_report.v1.schema.json`, `install_manifest.v1.json`, `install_manifest.v1.schema.json`, `install_report.v1.json`, `install_report.v1.schema.json`; versions in `VERSIONS.md`. Exemplars are compared as values, never as text: the order of the keys of a JSON object is not part of a contract (ADR 26).
