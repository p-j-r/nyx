# ADR 141: FEM-native eigenmode expansion (`Study::Eme`) and cross-mesh `Heat -> EME` coupling

## Status

Accepted (2026-11-27). Implements FR-37.

## Context

Long photonic and microwave waveguide components — directional couplers, multi-mode interferometers (MMIs), adiabatic tapers, 1,000-period distributed Bragg reflectors (DBRs), bent waveguide transitions, and millimetre-long thermo-optic phase shifters — span tens to thousands of guided wavelengths along wafer `+y`. Discretising the entire propagation length with volumetric 3D Nédélec elements (`Study::Driven`) scales linearly to superlinearly with device length `L`, even when the cross-section is piecewise invariant or periodic and when the design sweep only varies segment lengths `L_c`, Bragg period counts `N_rep`, or modal truncation `M`.

At the same time, `nyx` already solves high-order (`P1`/`P2`) 2D vector waveguide eigenmodes (`nyx_ems::modes` and `nyx_ems::modes_complex`) with curvilinear PMLs (ADR 128), midplane PEC/PMC symmetry (ADR 110), gyrotropic / non-symmetric `3 x 3` constitutive tensors with left-eigenvector biorthogonality (ADR 136), zero-thickness `sheet_2d` conductivities (ADR 137), temperature-dependent thermo-optic `dn/dT` including cryogenic Einstein-oscillator saturation (ADR 109), and domain-aware cross-mesh field transfer (`femcore::transfer`, ADR 135).

## Decision

### 1. Three-stage `Study::Eme` (`"eme"`) in `nyx-ems` (`ADR 9`)

Add `Study::Eme` (`dims: Dims::Three`, propagating along wafer `+y` with `exp(+j omega t - j beta y)`) implemented in `crates/nyx-ems/src/eme.rs`:

1. **Stage 1 (`assemble_eme`) — Partitioning, 3D-to-2D slicing, thermal/potential transfer, and BLAKE3 deduplication**:
   - `EmeGridSpec` partitions `y in [y0, y1]` hierarchically via `Uniform`, `Explicit`, `Composite`, and `PeriodicSubgrid { unit_cell, num_reps, unit_length }`.
   - Cross-section extraction uses a dual-path strategy on the 3D `SimplexMesh`:
     - *Vertical-prism slab fast path*: when straddling 3D cells form a straight vertical slab `[Y_k, Y_{k+1}]` (as generated by `extrude_y`, `sweep_model_3d`, or structured blocks), extracts the exact un-subdivided 2D base triangulation on `Y_k`, yielding bit-level parity with 2D `Study::Modes` and identical cross-sections independent of `y`.
     - *General marching-tetrahedra path*: for sloped sidewalls (adiabatic tapers) or unstructured 3D meshes, selects a deterministic vertex-free cut plane inside `[y_lo + 0.15 L_c, y_hi - 0.15 L_c]` and intersects straddling tetrahedra and 3D boundary/sheet facets along sorted 3D edges.
   - When `"temperature"` or `"potential"` is imported (either on a shared 3D mesh or across independent per-physics meshes via `Ctx::transferred_inputs` / `Problem::transferred_temperature`, ADR 135), `TransferIndex::eval_at_points` samples `T(x_q, y_c, z_q)` at every 2D Gauss quadrature point with **strict canonical `domain_names` filtering** so core/cladding thermal or material jumps are never smeared across interfaces.
   - Each slice's canonical 2D mesh, boundary conditions, `bend_radius`, gated `sheet_2d` potential, and quadrature-evaluated constitutive tensors (including local `ThermoOpticDomain::eval_at(T)`) are hashed with `blake3`. Identical slices map to a single `EmeUniqueSlice` and are solved **once**.

2. **Stage 2 (`solve_eme_cascade`) — Slice eigenmodes, cylindrical bends, cross-power overlaps, and Redheffer cascade**:
   - Lossless reciprocal straight slices without sub-cell thermal gradients take the real symmetric shift-invert solver (`modes`), falling back automatically to the quadrature-point complex solver (`assemble_slice_complex_quad` + `solve_mode_pairs_complex`) whenever PMLs, dielectric/sheet/IBC loss, tilted crystals, gyrotropy (`is_non_symmetric`), sub-cell `T(x, z)` gradients, or cylindrical waveguide bends are present.
   - **Bent waveguides**: on segments with `bend_radius = Some(R_bend)`, `conformal_bend_coord(x, R_bend) = R_bend ln(1 + x / R_bend)` validates `h_y(x) = 1 + x / R_bend > 1e-3` across the cross-section and applies the exact Ward–Pendry cylindrical metric pullback `T_bend = J_b^{-1} T J_b^{-T} det(J_b)` (`J_b = diag(1, h_y(x_q), 1)`) at every Gauss quadrature point.
   - **Unconditionally passive branch selection**: forward and backward propagation constants enforce `Im(beta) <= 0`, and `stable_prop_factor(beta, L_c)` evaluates `exp(min(Im(beta), 0) * L_c) * exp(-j Re(beta) L_c)`, guaranteeing `|P_c(m)| <= 1` without overflow on evanescent cutoff modes for arbitrarily long segments.
   - **Interface mode matching**: modes are normalized under the biorthogonal cross-section pairing `D_{mm} = int (e_tilde_m^* x h_m) . y_hat dS` (using true adjoint left eigenvectors on non-symmetric/gyrotropic slices and degenerate-cluster Gram–Schmidt orthogonalization). Adjacent slices form `(V_{LR}, W_{LR})` and the symmetric cross-power overlap `O_{c,c+1}(m, n) = 0.5 int (E_m^(c) x H_n^(c+1)* + E_n^(c+1)* x H_m^(c)) . y_hat dS` via shared-mesh `quad_rule(2, 6)` or symmetric two-mesh 24-point `fine_rule()` quadrature over `TransferIndex`. Solving `M_- S_if = M_+` yields unconditionally well-conditioned, unitary (`S_if^H S_if = I` on lossless propagating bases) interface scattering matrices for arbitrary mode counts `(M_L, M_R)`.
   - **Redheffer star product & periodic binary exponentiation**: segments and interfaces cascade via `S_A * S_B`; `PeriodicSubgrid` nodes evaluate `(S_cell * S_wrap)^{*(N_rep - 1)} * S_cell` in `O(log2 N_rep)` star products.
   - Both automatic end-slice modal ports (`p1_m1..`, `p2_m1..`) and explicit 3D `waveport` boundary patches on `y = y0` / `y = y1` are supported.

3. **Stage 3 (`eme_fields`) — `DrivenPortData`, `EmeData` cache, and 3D field reconstruction**:
   - Emits `DrivenPortData` (`S`, `Z`, `Y` matrices) so `nyx_analysis::network` and Touchstone `.sNp` export work unchanged on `eme` results.
   - Serializes `EmeData` under `EME_DATA_KEY = "eme cascade data"` in `SolveResult::scalars`, retaining `beta_fwd`, `beta_bwd`, the `EmeCascadeNode` tree, and raw `(d_left, d_right_tilde, v_lr, w_lr)` overlap blocks.
   - Reconstructs bounded 3D electric fields (`|E|`, `Re Ex`, `Re Ey`, `Re Ez` and complex `CellFields`) via prefix/suffix Redheffer sweeps so forward waves decay from `y_lo` (`+y`) and backward waves decay from `y_hi` (`-y`) with zero exponential blowup.

### 2. Zero-re-solve sweeps (`eme_sweep`) and one-way `Heat -> EME` coupling

- `nyx_ems` exports `eme_length_sweep`, `eme_periodicity_sweep`, and `eme_mode_sweep`, exposed in `nyx-engine` as the read-only command `eme_sweep` (`mode = "length" | "periodicity" | "modes"`). All three sweeps operate purely on cached `EmeData` in sub-millisecond time with zero 2D eigensolves and zero mesh access.
- `Ems::study_exports("eme")` narrows exports to `ems.E` (`optical_field`), omitting volumetric `heat_source` so `Registry::solve_order_for_studies` schedules one-way `dfs::heat_stationary -> ems::eme` thermo-optic chains automatically without requiring `coupled_loop`.

## Consequences

- **Positive**: Multi-millimetre couplers, tapers, thermo-optic phase shifters, and 1,000-period Bragg gratings solve in milliseconds to fractions of a second while preserving full-vector FEM cross-section accuracy, curvilinear PMLs, gyrotropy, `sheet_2d` layers, and domain-filtered cross-mesh `Heat -> EME` coupling.
- **Trade-offs**: EME assumes piecewise `y`-invariant segments (approximating continuous tapers by staircase cross-sections whose accuracy converges systematically with `n_cells` and `n_modes`, directly quantifiable via `eme_mode_sweep`).
