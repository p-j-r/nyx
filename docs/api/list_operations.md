# `list_operations`

**List the geometry operations** · access `read`: reads the project or the results

Every geometry operation with its fields, types and defaults (what the add_* commands take).

## Arguments

None.

Lengths are in metres and every unit is SI unless the argument says otherwise.

## Example

A line of a command list (`nyx check`, `nyx run`), made from the schema with placeholder values (`<...>` is text to replace):

```json
{"cmd":"list_operations","args":{}}
```
