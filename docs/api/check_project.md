# `check_project`

**Check the project** · access `read`: reads the project or the results

Checks the geometry, the element size and every problem against the descriptors of its physics, without meshing.

## Arguments

None.

Lengths are in metres and every unit is SI unless the argument says otherwise.

## Example

A line of a command list (`nyx check`, `nyx run`), made from the schema with placeholder values (`<...>` is text to replace):

```json
{"cmd":"check_project","args":{}}
```
