# `geometry_names`

**Evaluate the geometry and list its names** · access `read`: reads the project or the results

Evaluates the model and returns the region and boundary names a problem can use, and the bounding box. Instant; it reports a geometry that does not evaluate.

## Arguments

None.

Lengths are in metres and every unit is SI unless the argument says otherwise.
