# `project_info`

**Project summary** · access `read`: reads the project or the results

Title, geometry size, the problem of each physics, the mesh, the results (and whether they are stale), the store binding and the jobs.

## Arguments

None.

Lengths are in metres and every unit is SI unless the argument says otherwise.

## Example

A line of a command list (`nyx check`, `nyx run`), made from the schema with placeholder values (`<...>` is text to replace):

```json
{"cmd":"project_info","args":{}}
```
